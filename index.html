🚀 Quick Start

Prerequisites

  • Node.js 18+
  • Python 3.8+
  • Redis instance (local or cloud)

1. Clone Repository

git clone https://github.com/yourusername/email-validator-saas.git
cd email-validator-saas

2. Frontend Setup

cd frontend
npm install
npm start

3. Backend Setup

cd api
pip install -r requirements.txt

4. Environment Variables

Create .env file in the root directory:

# Redis Configuration
REDIS_URL=redis://localhost:6379/0

# Production (when ready)
STRIPE_SECRET_KEY=sk_live_...
STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Optional
CUSTOM_DOMAIN=yourdomain.com
SENTRY_DSN=https://...
ANALYTICS_ID=G-...

5. Start Development

# Terminal 1 - Frontend
cd frontend && npm start

# Terminal 2 - Backend (if using local development)
cd api && python -m http.server 8000

Validation Settings

    def __init__(self):
        self.timeout = 20  # SMTP timeout
        self.max_retries = 3  # Retry attempts
